# v0.1.0 Design Notes

v0.1.0 is intentionally scoped to a runnable engineering loop.

## Implemented scope

- Project scaffolding.
- Markdown/txt ingestion.
- PDF placeholder copy.
- Rule-based keyword analysis.
- Model ledger scaffold.
- Experiment plan scaffold.
- Lightweight BOC-like demo.
- Artifact saving.
- Project report.
- Multi-agent handoff.
- Mock API usage accounting.

## Non-goals

- Full paper reading.
- Verified formula extraction.
- Complete BOC acquisition/tracking implementation.
- Real API provider integration.
- Benchmark claims.

## Demo rationale

The BOC-like demo is small enough to run quickly but representative enough to exercise data generation, plotting, metrics, metadata, logs, and reporting.
