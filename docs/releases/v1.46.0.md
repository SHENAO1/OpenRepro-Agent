# OpenRepro-Agent v1.46.0

v1.46.0 adds asset-centric incremental build planning and guarded materialization.

## Added

- `openrepro assets plan/materialize/summary`.
- `workspace/asset_build_plan.json` and `workspace/ASSET_BUILD_PLAN.md`.
- `workspace/asset_materialization.json` and `workspace/ASSET_MATERIALIZATION.md`.
- A `local_ui` workflow DAG step in the delivery preset and refresh pipeline.

## Behavior

- Asset build planning reads workflow state and asset catalog records.
- Safe runnable workflow steps with missing outputs become materialization candidates.
- Unsafe source input, human decisions, repairs, and experiment execution remain blocked.
- Confirmed materialization delegates execution to the existing workflow executor.

## Guardrail

Materialization is a dry run unless `--confirm` is passed. Even when confirmed, only workflow steps already marked safe can execute.
