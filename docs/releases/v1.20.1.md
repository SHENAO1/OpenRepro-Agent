# OpenRepro-Agent v1.20.1

OpenRepro-Agent v1.20.1 adds project-level acceptance criteria derived from
the project profile and existing workflow evidence.

## Added

- `openrepro acceptance`
- `workspace/acceptance_criteria.json`
- `workspace/ACCEPTANCE_CRITERIA.md`
- Acceptance status fields in `inspect`, `status`, reports, handoff, freshness,
  dashboards, refresh runs, and evidence packages.

## Policy

Acceptance criteria evaluate workflow readiness gates only. They do not claim
scientific reproduction success.
