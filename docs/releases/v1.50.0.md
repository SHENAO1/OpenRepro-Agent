# OpenRepro-Agent v1.50.0

v1.50.0 adds local security policy initialization and static audit artifacts.

## Added

- `openrepro security init/audit/summary`.
- `workspace/security_policy.json`.
- `workspace/SECURITY_POLICY.md`.
- `workspace/security_audit.json`.
- `workspace/SECURITY_AUDIT.md`.

## Behavior

- Scans configured project text roots for likely secrets.
- Checks local validation summaries, GitHub workflow trigger declarations, and plugin registry path references.
- Surfaces security audit status in the local UI, evidence package, asset catalog, dashboard links, evidence explorer links, and local PR summary checks.

## Guardrail

Security audits are local and static. Secret findings report pattern names and file locations only; matched secret values are not written to audit outputs.
