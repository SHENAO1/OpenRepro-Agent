# OpenRepro-Agent v0.9.2

OpenRepro-Agent v0.9.2 adds experiment input calibration commands.

## Added

- Added `openrepro validate-inputs`.
- Added `openrepro set-input`.
- Added input source tracking for `verified_candidate`, `manual_override`, and
  `default`.
- Added workspace validation artifacts:
  `workspace/experiment_input_validation.json` and
  `workspace/EXPERIMENT_INPUT_VALIDATION.md`.

## Changed

- `inspect` and `status` now surface missing required input counts.
- `run-experiment` refreshes input validation and records warnings in run
  evidence.
- Smoke tests now calibrate template inputs before running the BOC-like
  experiment template.

## Guardrail

Manual input overrides are engineering assumptions. They must be reviewed
against the paper before any reproduction claim.
