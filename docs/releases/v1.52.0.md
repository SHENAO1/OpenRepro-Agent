# OpenRepro-Agent v1.52.0

v1.52.0 adds declaration-only integration exports for common experiment tooling.

## Added

- `openrepro integrations export/summary`.
- MLflow run context export.
- Aim run context export.
- DVC stage template export.
- Hydra config template export.
- `workspace/integrations.json` and `workspace/INTEGRATIONS.md`.

## Policy

Integration exports are supervised handoff artifacts only. OpenRepro-Agent does not import, install, or execute MLflow, Aim, DVC, or Hydra in this release, and these files do not prove scientific reproduction success.
