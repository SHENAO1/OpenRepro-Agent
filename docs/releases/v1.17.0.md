# OpenRepro-Agent v1.17.0

OpenRepro-Agent v1.17.0 adds role-based collaboration packs for project
handoff.

## Added

- Added `openrepro collaboration-pack`.
- Added `src/openrepro/collaboration_pack.py`.
- Added `handoff/collaboration_pack.json`, `handoff/COLLABORATION_PACK.md`, and
  optional `handoff/collaboration_pack.zip`.
- Surfaced collaboration pack status in `status`, `inspect`, reports, handoff,
  and evidence package summaries.

## Policy

Collaboration packs coordinate workflow handoff only. They do not prove
scientific reproduction.
