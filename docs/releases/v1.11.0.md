# OpenRepro-Agent v1.11.0

OpenRepro-Agent v1.11.0 adds protocol action plans.

## Added

- Added `openrepro protocol-plan`.
- Added `workspace/protocol_plan.json` and `workspace/PROTOCOL_PLAN.md`.
- Converted protocol coverage gaps into prioritized workflow actions.
- Surfaced protocol plan status in `inspect`, `status`, reports, handoff, and evidence packages.

## Policy

Protocol plans are advisory workflow previews only. They do not execute commands, fill placeholder values, or prove scientific reproduction.
