# OpenRepro-Agent v1.21.1

OpenRepro-Agent v1.21.1 adds readiness review freshness and consistency
validation.

## Added

- `openrepro validate-readiness-review`
- `reports/readiness_review_validation.json`
- `reports/READINESS_REVIEW_VALIDATION.md`
- Validation status fields in `inspect`, `status`, reports, handoff, refresh
  runs, and CLI output.

## Policy

Readiness review validation checks freshness and internal consistency for the
final review report only. It does not claim scientific reproduction success.
