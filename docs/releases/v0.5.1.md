# OpenRepro-Agent v0.5.1

OpenRepro-Agent v0.5.1 makes the v0.5.0 approval and repair-preview state
visible across the main project surfaces.

## Added

- `openrepro inspect` now reports verified formula/parameter counts, approval
  status, latest repair dry-run status, and dry-run action counts.
- Project reports now include verified candidate and repair dry-run summaries.
- Handoff generation now includes `VERIFIED_CANDIDATES.md` and
  `REPAIR_DRY_RUN.md`.
- Project status now suggests `approve-candidates` after analysis and planning
  when candidate evidence exists but no verified candidate artifact is present.

## Policy

This release only surfaces review state. It does not change the rule that
candidate approval and repair previews are auditable workflow evidence, not
scientific reproduction claims.
