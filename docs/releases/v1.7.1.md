# OpenRepro-Agent v1.7.1

OpenRepro-Agent v1.7.1 adds actionable reproduction workflow gaps.

## Added

- Added `openrepro gaps`.
- Added `openrepro todo` as an alias for generating the same gap artifacts.
- Added `workspace/reproduction_gaps.json` and `workspace/REPRODUCTION_GAPS.md`.
- Added severity-ranked suggested commands for upstream workflow gaps.
- Added gap summaries to `inspect`, `status`, reports, handoff files, and evidence packages.

## Notes

- Gaps are workflow to-dos only.
- A clear gaps list does not prove that any paper claim has been scientifically reproduced.
