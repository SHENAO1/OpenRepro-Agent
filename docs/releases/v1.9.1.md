# OpenRepro-Agent v1.9.1

OpenRepro-Agent v1.9.1 adds human review decision records for review board
items.

## Highlights

- Added `openrepro review-decision`.
- Added `workspace/review_decisions.json` and `workspace/REVIEW_DECISIONS.md`.
- Supported `resolved`, `rejected`, `deferred`, and `needs_followup` decisions.
- Tracked unresolved review board items after the latest human decision.
- Surfaced review decision status in `inspect`, `status`, reports, handoff
  files, and evidence packages.

## Guardrail

Review decisions record workflow handling only. Closing a review item does not
validate formulas, data, code, outputs, or scientific reproduction success.
