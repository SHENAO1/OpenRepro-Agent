# OpenRepro-Agent v1.6.0

OpenRepro-Agent v1.6.0 adds claim-to-evidence traceability.

## Added

- Added `openrepro trace-claims`.
- Added `workspace/claim_trace.json` and `workspace/CLAIM_TRACE.md`.
- Added `claim_contract` to experiment specs.
- Added claim trace summaries to `inspect`, `status`, and evidence packages.
- Linked formula/parameter candidates, verified claims, experiment scaffolds, registered data, and run evidence.

## Notes

- Claim traces are audit maps only.
- A linked claim is not a scientific reproduction result unless a human independently verifies the formula, parameters, data, implementation, and outputs.
