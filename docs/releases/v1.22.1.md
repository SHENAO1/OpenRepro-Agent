# OpenRepro-Agent v1.22.1

OpenRepro-Agent v1.22.1 adds final workflow delivery bundles.

## Added

- `openrepro delivery-bundle`
- `reports/delivery_bundle.json`
- `reports/DELIVERY_BUNDLE.md`
- Optional `reports/delivery_bundle.zip`
- Delivery bundle status fields in `inspect`, `status`, reports, handoff,
  refresh runs, and CLI output.

## Policy

Delivery bundles organize existing final workflow handoff artifacts only. They
do not run experiments, close human decisions, fabricate missing scientific
artifacts, or claim scientific reproduction success.
