# OpenRepro-Agent v0.6.2

OpenRepro-Agent v0.6.2 is a stability and health-check release before the
controlled experiment execution layer.

## Added

- Added `openrepro doctor` with dependency, project structure, config, and
  provider readiness checks.
- Added `workspace/doctor.json` and `workspace/DOCTOR.md`.
- Surfaced lineage status in `inspect`, `status`, and handoff outputs.
- Added `handoff/RUN_LINEAGE.md`.
- Expanded smoke tests to cover approval, lineage, repair dry-run/apply, and
  doctor commands.

## Policy

Doctor and lineage status checks report workflow readiness only. They do not
claim scientific reproduction success.
