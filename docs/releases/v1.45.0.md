# OpenRepro-Agent v1.45.0

v1.45.0 adds a read-only static local UI console for navigating project artifacts.

## Added

- `openrepro serve build/summary`.
- `reports/local_ui/index.html`.
- `reports/local_ui_manifest.json`.
- `workspace/local_ui_summary.json` and `workspace/LOCAL_UI_SUMMARY.md`.
- Optional `reports/local_ui.zip`.

## Behavior

- The local UI groups workflow, asset, experiment, review, agent, and CI summaries into tabbed static HTML.
- It links to existing dashboards, evidence explorers, run browsers, experiment tracking, asset catalogs, cache reports, agent reports, and CI artifacts.
- It excludes its generated outputs from evidence fingerprints and asset catalog recursion.

## Guardrail

The local UI reads existing artifacts only. It does not start a server, run experiments, refresh derived outputs, close review decisions, or claim scientific reproduction.
