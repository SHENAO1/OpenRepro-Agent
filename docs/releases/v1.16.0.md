# OpenRepro-Agent v1.16.0

OpenRepro-Agent v1.16.0 adds a static review site for human-facing evidence
handoff.

## Added

- Added `openrepro review-site`.
- Added `src/openrepro/review_site.py`.
- Added `reports/review_site/index.html`, `reports/review_site_manifest.json`,
  and optional `reports/review_site.zip` outputs.
- Surfaced review site status in `status`, `inspect`, reports, handoff, and
  evidence package summaries.

## Policy

Review sites present workflow evidence for human review. They do not prove
scientific reproduction.
