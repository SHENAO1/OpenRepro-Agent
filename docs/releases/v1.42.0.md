# OpenRepro-Agent v1.42.0

v1.42.0 adds experiment metric evaluation suites and leaderboards.

## Added

- `openrepro eval define/run`.
- `openrepro experiments leaderboard`.
- `workspace/evaluation_registry.json` and `workspace/EVALUATION_REGISTRY.md`.
- `workspace/evaluation_results.json` and `workspace/EVALUATION_RESULTS.md`.
- `workspace/experiment_leaderboard.json` and `workspace/EXPERIMENT_LEADERBOARD.md`.

## Behavior

- Evaluation suites declare metric thresholds and comparison operators.
- Evaluation runs compare latest tracked experiment metrics against those thresholds.
- Leaderboards rank latest tracked metrics with missing values placed last.

## Guardrail

Evaluations and leaderboards summarize observed workflow metrics only. They do not prove scientific correctness or paper reproduction success.
