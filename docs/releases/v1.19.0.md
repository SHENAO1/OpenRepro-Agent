# OpenRepro-Agent v1.19.0

OpenRepro-Agent v1.19.0 adds a static project dashboard for handoff and artifact
navigation.

## Changes

- Added `openrepro dashboard`.
- Added `src/openrepro/dashboard.py`.
- Added `reports/dashboard/index.html`, `reports/dashboard_manifest.json`, and
  optional `reports/dashboard.zip`.
- Combined readiness score, artifact freshness, refresh run, collaboration pack,
  timeline, reviewer packet, review site, evidence package, and handoff links.
- Surfaced dashboard status in `status`, `inspect`, reports, handoff, review
  sites, and evidence packages.
- Added dashboard generation to the refresh pipeline.

## Policy

Dashboards are static project handoff views. They do not verify scientific
correctness or prove reproduction.
