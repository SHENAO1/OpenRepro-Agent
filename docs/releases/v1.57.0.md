# OpenRepro-Agent v1.57.0

v1.57.0 adds a unified Evidence Graph for reviewing paper-reproduction workflow state across claims, sources, data, experiments, runs, review decisions, and key artifacts.

## Added

- `openrepro evidence-graph`.
- `workspace/evidence_graph.json` and `workspace/EVIDENCE_GRAPH.md`.
- Evidence Graph summaries in evidence packages.
- Evidence Graph status and next-action coverage in the reproduction cockpit.
- Evidence Graph execution in the registered workflow DAG and refresh pipeline.
- Tests for direct graph generation, CLI generation, and evidence package inclusion.

## Policy

The Evidence Graph is an audit map over existing workflow artifacts. It does not run experiments, verify scientific correctness, promote candidate claims, fabricate missing evidence, or claim paper reproduction success.
