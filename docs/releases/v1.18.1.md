# OpenRepro-Agent v1.18.1

OpenRepro-Agent v1.18.1 adds artifact freshness graphs for explaining why
derived workflow artifacts are current, stale, or missing.

## Changes

- Added `openrepro freshness`.
- Added `src/openrepro/freshness.py`.
- Added `workspace/artifact_freshness.json` and
  `workspace/ARTIFACT_FRESHNESS.md`.
- Compared evidence package source fingerprints against current project
  evidence and summarized added, removed, and changed files.
- Surfaced top stale node, top stale reason, and suggested command in `status`,
  `inspect`, reports, handoff, and evidence packages.
- Added artifact freshness generation to the refresh pipeline.

## Policy

Artifact freshness graphs explain workflow artifact state only. They do not
verify scientific correctness or prove reproduction.
