# OpenRepro-Agent v1.20.0

OpenRepro-Agent v1.20.0 adds a project reproduction profile that defines scope
before reports, evidence packages, and handoff artifacts are finalized.

## Added

- `openrepro profile`
- `workspace/project_profile.json`
- `workspace/PROJECT_PROFILE.md`
- Profile status fields in `inspect`, `status`, reports, handoff, dashboard,
  artifact freshness, refresh, and evidence packages.

## Policy

Project profiles define reproduction goals, target claims, required data,
required experiments, and acceptance dimensions. They do not claim scientific
reproduction success.
