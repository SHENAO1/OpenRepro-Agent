# OpenRepro-Agent v1.32.0

v1.32.0 adds searchable evidence query artifacts on top of the static evidence explorer.

## Added

- `openrepro evidence-query` for searching evidence explorer records by kind and text.
- `workspace/evidence_query.json` and `workspace/EVIDENCE_QUERY.md`.
- Workflow DAG step `evidence_query` after `evidence_explorer`.

## Changed

- Refresh now generates a default evidence query after the evidence explorer.
- Dashboard and evidence explorer artifact links include `EVIDENCE_QUERY.md` when present.

## Guardrails

- Evidence queries organize workflow evidence for review only.
- They do not verify scientific correctness or claim reproduction success.
