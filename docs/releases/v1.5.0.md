# OpenRepro-Agent v1.5.0

OpenRepro-Agent v1.5.0 connects failed quality gates to repair planning.

## Added

- Added check-specific quality gate diagnosis codes.
- Added quality-gate-aware repair-plan automation labels.
- Added repair dry-run previews for missing metrics, failed manifests, runner failures, and missing snapshots.
- Added quality gate summary context to `workspace/repair_plan.json`.

## Notes

- Repair dry-runs preview recovery actions only.
- The workflow still refuses to fabricate metrics, snapshots, datasets, or scientific outputs.
