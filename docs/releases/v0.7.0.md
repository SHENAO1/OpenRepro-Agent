# OpenRepro-Agent v0.7.0

OpenRepro-Agent v0.7.0 adds controlled execution for verified experiment
scaffolds.

## Added

- Added `openrepro run-experiment`.
- Added `src/openrepro/experiment_runner.py`.
- Added `run-experiment` manifest requirements.
- Added execution artifacts: runner log, execution result JSON, experiment
  report, config snapshot, runner copy, metadata, and manifest.

## Policy

`run-experiment` requires `--confirm` and `verified_inputs_ready`. A successful
runner exit is execution evidence only; it is not a paper reproduction claim.
