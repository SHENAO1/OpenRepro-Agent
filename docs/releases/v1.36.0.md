# OpenRepro-Agent v1.36.0

v1.36.0 adds lightweight data expectation suites and validation results.

## Added

- `openrepro data-expectations init/run`.
- `workspace/data_expectations.json` and `workspace/DATA_EXPECTATIONS.md`.
- `workspace/data_expectation_results.json` and `workspace/DATA_EXPECTATION_RESULTS.md`.
- Default expectations derived from data profiles: row count minimum, not-null, inferred type, and observed numeric range checks.

## Changed

- Refresh now runs data expectations after data profile and before the repro lock.
- The workflow DAG includes `data_expectations` before environment locking.
- Evidence packages include data expectation suites and results.

## Guardrails

- Data expectations validate lightweight structural contracts only.
- They do not verify dataset semantics, labels, provenance claims, or scientific data quality.
