# OpenRepro-Agent v1.56.0

v1.56.0 adds a static reproduction cockpit for quickly reviewing project health and the next actionable workflow steps.

## Added

- `openrepro cockpit build/summary`.
- `reports/cockpit/index.html` and `reports/cockpit_manifest.json`.
- `workspace/cockpit_summary.json` and `workspace/COCKPIT_SUMMARY.md`.
- Optional `reports/cockpit.zip` export for handoff.
- Cockpit summaries for readiness, gaps, data quality, dataset cards, claim trace validation, runs, OpenRepro-Bench Lite, integration execution, evidence freshness, and review decisions.
- Ordered next actions with suggested commands for missing or stale workflow evidence.
- Cockpit links in evidence packages, dashboards, and readiness reviews.

## Policy

The cockpit is a read-only review surface over existing project artifacts. It does not run experiments, repair artifacts, execute integrations, or prove scientific reproduction.
