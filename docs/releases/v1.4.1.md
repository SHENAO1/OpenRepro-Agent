# OpenRepro-Agent v1.4.1

OpenRepro-Agent v1.4.1 makes quality gates easier to audit across a whole project.

## Added

- Added `openrepro quality-gate --all`.
- Added `workspace/quality_gate_summary.json` and `workspace/QUALITY_GATE_SUMMARY.md`.
- Added failed quality gate check names to inspect summaries, run summaries, and evidence packages.
- Added quality gate failure issues to `diagnose`.
- Added separate latest-run and latest-experiment-run gate status in `status`.

## Notes

- Missing quality gate reports are still surfaced through `status`; `diagnose` focuses on gates that exist and fail.
- Quality gate summaries remain workflow evidence only, not scientific validation.
