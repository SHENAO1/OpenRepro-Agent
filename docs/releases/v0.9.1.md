# OpenRepro-Agent v0.9.1

OpenRepro-Agent v0.9.1 adds environment snapshots and stronger run lineage for
experiment executions.

## Added

- Added `configs/environment_snapshot.json` for `run-experiment`.
- Recorded Python version, platform, dependency versions, random seed, and
  runner SHA-256.
- Added a lightweight same-seed repeatability check against prior experiment
  runs.
- Extended run lineage with experiment config, input, environment, and runner
  hashes.

## Changed

- Added environment snapshots to run-experiment required artifacts.
- Updated reports and metadata with environment snapshot and repeatability
  status.

## Guardrail

Environment snapshots and same-seed checks are engineering evidence. They do
not prove scientific reproduction without independent review of formulas,
parameters, code, data, and outputs.
