# OpenRepro-Agent v1.27.0

OpenRepro-Agent v1.27.0 adds a registered workflow DAG for status inspection, step explanation, and guarded safe derived-step execution.

## Added

- `openrepro workflow status`
- `openrepro workflow explain`
- `openrepro workflow run`
- `openrepro workflow resume`
- `workspace/workflow_state.json`
- `workspace/WORKFLOW_STATE.md`
- `workspace/workflow_run.json`
- `workspace/WORKFLOW_RUN.md`

## Changed

- Major workflow steps are now declared in a registry with dependencies, expected outputs, safety flags, execution class, and command hints.
- Workflow run and resume are dry-run by default and require `--confirm` for safe derived-step execution.

## Guardrails

- Workflow-managed execution is limited to safe derived artifacts.
- It does not run experiments.
- It does not ingest sources or data.
- It does not record human review decisions or claim signoffs.
- It does not apply repairs.
- It does not claim scientific reproduction success.
