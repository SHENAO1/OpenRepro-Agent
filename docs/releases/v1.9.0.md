# OpenRepro-Agent v1.9.0

OpenRepro-Agent v1.9.0 adds a consolidated human review board for outstanding
workflow review items.

## Highlights

- Added `openrepro review-board`.
- Added `workspace/review_board.json` and `workspace/REVIEW_BOARD.md`.
- Aggregated candidate review, high-risk candidate, data validation,
  experiment spec, claim trace, scorecard, gaps, and advance-plan prompts.
- Surfaced review board status in `inspect`, `status`, reports, handoff files,
  and evidence packages.

## Guardrail

The review board is an advisory workflow queue. Clearing it means no open human
review prompts were detected; it does not prove scientific reproduction success.
