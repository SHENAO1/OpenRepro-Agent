# OpenRepro-Agent v0.5.2

OpenRepro-Agent v0.5.2 strengthens provider safety and cache controls while
preserving the default mock-only posture.

## Added

- Added prompt/response preview redaction for likely API keys, tokens, secrets,
  emails, and long key-like strings.
- Added provider cache namespaces in the form `<provider>/<model>/<task>`.
- Added API config fields: `cache_enabled`, `cache_ttl_seconds`, and
  `redact_prompts`.
- Added `configure-provider` flags for cache and redaction policy.
- Added usage-record fields for redacted previews, cache policy, and cache
  namespace metadata.

## Policy

Usage records keep request hashes and redacted previews for auditability. They
do not store full prompts or unredacted secret-looking values by default.
