# OpenRepro-Agent v1.2.0

OpenRepro-Agent v1.2.0 adds experiment specification contracts.

## Added

- Added `experiments/<id>/experiment_spec.json`.
- Added `openrepro validate-experiment-spec`.
- Added spec validation before `run-experiment`.
- Added `configs/experiment_spec_snapshot.json` to experiment run outputs and
  required manifests.
- Added experiment spec hashes to comparison and lineage outputs.
- Added spec summaries to evidence packages.

## Policy

Experiment specs define engineering contracts for execution and comparison.
They do not verify scientific correctness or paper reproduction success.
