# OpenRepro-Agent v1.2.1

OpenRepro-Agent v1.2.1 makes experiment specs freshness-aware.

## Added

- Added stable source fingerprints to `experiments/<id>/experiment_spec.json`.
- Added non-mutating spec freshness inspection for `inspect`, `status`, and evidence packages.
- Added `openrepro validate-experiment-spec --strict` to fail on stale specs or warnings without refreshing the saved contract.
- Added comparison warnings when two same-experiment runs use different spec hashes.

## Notes

- Normal validation still refreshes stale specs so operators can bring the saved contract back in sync.
- Strict validation is an engineering guardrail only; it does not verify scientific correctness.
