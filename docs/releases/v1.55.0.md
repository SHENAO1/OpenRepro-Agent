# OpenRepro-Agent v1.55.0

v1.55.0 adds dataset cards and lightweight data quality gates for registered project data.

## Added

- `openrepro dataset-card generate/summary`.
- `openrepro data-quality run/summary`.
- `workspace/dataset_card.json` and `workspace/DATASET_CARD.md`.
- `workspace/data_quality_gate.json` and `workspace/DATA_QUALITY_GATE.md`.
- Dataset summaries for hashes, formats, rows, columns, missingness, sampled duplicates, label-like columns, and split-like columns.
- Evidence package, dashboard, and readiness review summaries for dataset card and data quality status.

## Policy

Dataset cards and data quality gates perform structural checks only. They do not verify dataset semantics, labels, provenance claims, or scientific correctness.
