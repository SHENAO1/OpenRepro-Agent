# OpenRepro-Agent v1.44.0

v1.44.0 adds local GitHub Actions CI scaffold generation and validation.

## Added

- `openrepro ci init/validate/summary`.
- `.github/workflows/openrepro-ci.yml`.
- `workspace/ci_summary.json` and `workspace/CI_SUMMARY.md`.
- `workspace/ci_validation.json` and `workspace/CI_VALIDATION.md`.

## Behavior

- The generated workflow runs on push and pull request.
- It uses a Python matrix, editable package install, `openrepro --version`, and a configurable pytest command.
- Validation checks local workflow contents for required smoke and test steps.

## Guardrail

CI integration generates and validates local configuration only. It does not claim that remote GitHub Actions has run or passed.
