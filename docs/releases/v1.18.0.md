# OpenRepro-Agent v1.18.0

OpenRepro-Agent v1.18.0 adds a guarded refresh pipeline for derived workflow
and handoff artifacts.

## Changes

- Added `openrepro refresh`.
- Added `src/openrepro/refresh.py`.
- Added `workspace/refresh_run.json`, `workspace/REFRESH_RUN.md`, and optional
  `workspace/refresh_run.zip`.
- Refresh runs regenerate derived artifacts without running experiments,
  adding human signoffs, resolving review decisions, or fabricating missing
  scientific artifacts.
- Surfaced refresh run status in `status`, `inspect`, reports, handoff, and
  evidence packages.

## Policy

Refresh runs are orchestration records for existing workflow evidence. They do
not prove scientific reproduction.
