# OpenRepro-Agent v1.33.0

v1.33.0 adds registered data profiles and lightweight schema warnings.

## Added

- `openrepro data-profile`.
- `workspace/data_profile.json` and `workspace/DATA_PROFILE.md`.
- Profiling for registered CSV, TSV, JSON, and JSONL files.
- Column-level inferred value types, null ratios, sampled distinct counts, and numeric ranges.

## Changed

- Refresh now runs data profiling after data validation and before the repro lock.
- The workflow DAG includes `data_profile` before environment locking.
- Dashboards, evidence explorers, and evidence packages can surface data profile artifacts.

## Guardrails

- Data profiles inspect structure and simple sampled values only.
- They do not verify dataset semantics, labels, provenance claims, or scientific data quality.
