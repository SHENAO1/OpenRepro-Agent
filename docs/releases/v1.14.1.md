# OpenRepro-Agent v1.14.1

OpenRepro-Agent v1.14.1 adds claim evidence report validation.

## Added

- Added `openrepro validate-claim-evidence-report`.
- Added `reports/claim_evidence_report_validation.json` and `reports/claim_evidence_report_validation.md`.
- Detected stale reports when binder evidence, binder validation, or claim signoffs change.
- Surfaced claim evidence report validation status in `inspect`, `status`, reports, handoff, and evidence packages.

## Policy

Claim evidence report validation checks report freshness and consistency. It does not prove scientific reproduction.
