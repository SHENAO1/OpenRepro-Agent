# OpenRepro-Agent v1.23.0

OpenRepro-Agent v1.23.0 adds guarded multi-agent coordination plans.

## Added

- `openrepro multi-agent-plan`
- `workspace/multi_agent_plan.json`
- `workspace/MULTI_AGENT_PLAN.md`
- Maintainer, reviewer, experimenter, and next-agent role definitions
- Multi-agent task assignment from review action plans, collaboration packs,
  delivery bundles, and project status
- Multi-agent plan status fields in `inspect`, `status`, reports, handoff,
  refresh runs, and CLI output

## Policy

Multi-agent plans are advisory coordination artifacts. They do not execute
agents, run experiments, close human decisions, add signoffs, fabricate missing
scientific artifacts, or claim scientific reproduction success.
