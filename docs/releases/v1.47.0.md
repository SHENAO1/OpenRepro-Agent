# OpenRepro-Agent v1.47.0

v1.47.0 adds a declarative plugin registry and validation layer.

## Added

- `openrepro plugins register/list/validate/summary`.
- `openrepro.plugins.yaml`.
- `workspace/plugin_registry.json` and `workspace/PLUGIN_REGISTRY.md`.
- `workspace/plugin_validation.json` and `workspace/PLUGIN_VALIDATION.md`.

## Behavior

- Plugins can be declared as `command`, `provider`, `reporter`, or `evaluator`.
- Run modes are `declaration`, `external_supervised`, and `safe_command`.
- Validation checks slug-safe ids, allowed kinds, allowed run modes, entrypoints, duplicate ids, and unsafe safe-command declarations.
- Local UI, dashboards, evidence explorers, and evidence packages surface plugin registry artifacts when present.

## Guardrail

Plugin registry generation and validation never import, load, or execute plugin code. Unsafe commands remain blocked for `safe_command` declarations.
