# OpenRepro-Agent v0.8.1

OpenRepro-Agent v0.8.1 adds starter experiment templates and makes
`run-experiment` respect scaffold-declared expected artifacts.

## Added

- Added `--template basic|boc-like|numeric-sweep` to `openrepro scaffold-experiment`.
- Added runnable BOC-like and numeric-sweep starter runners for verified scaffolds.
- Added `OPENREPRO_RUN_DIR`, `OPENREPRO_EXPERIMENT_ID`, and
  `OPENREPRO_EXPERIMENT_TEMPLATE` environment variables for scaffold runners.

## Changed

- Updated scaffold `expected_artifacts.json` to match the current
  `run-experiment` output layout.
- Updated `run-experiment` manifests to include template-specific required
  artifacts.
- Made `run-experiment` fail when a completed runner omits required template
  artifacts.
- Updated README, roadmap, smoke scripts, and tests for the v0.8.1 workflow.

## Guardrail

Template outputs are execution evidence only. They do not claim scientific
reproduction success without independent human verification of formulas,
parameters, code, data, and outputs.
