# OpenRepro-Agent v1.0.1

OpenRepro-Agent v1.0.1 stabilizes evidence packages for handoff workflows.

## Added

- Added source fingerprints for evidence package freshness checks.
- Added artifact SHA-256 hashes to evidence package workspace summaries.
- Added `openrepro evidence-package --zip`.
- Added `handoff/EVIDENCE_PACKAGE.md`.
- Added status output for evidence package freshness.

## Tests

- Added regression coverage for current/stale package detection.
- Added zip export coverage.

## Policy

Freshness and zip exports report engineering evidence state only. They do not
claim scientific reproduction success.
