# OpenRepro-Agent v0.6.1

OpenRepro-Agent v0.6.1 adds confirmed manifest-only repair application.

## Added

- Added `openrepro repair --apply --only manifest --confirm`.
- Added `workspace/repair_apply.json` and `workspace/REPAIR_APPLY.md`.
- Added tests proving manifest repair can turn a manifest mismatch back into a
  valid run manifest.

## Policy

Apply mode is intentionally narrow. It only regenerates `manifest.json` from
files already present on disk. It does not create missing scientific artifacts,
edit experiment code, change config values, or infer parameters.
