# OpenRepro-Agent v0.8.2

OpenRepro-Agent v0.8.2 makes experiment templates discoverable and easier to
diagnose before a run.

## Added

- Added `openrepro list-templates`.
- Added a shared experiment template registry with purpose, use case, required
  artifacts, optional artifacts, and input hints.
- Added experiment scaffold template counts and expected-artifact attention
  counts to `inspect` and `status`.
- Added scaffold diagnostics for missing, legacy, mismatched, or tampered
  `expected_artifacts.json` files.

## Changed

- Updated scaffold and run schema versions to v0.8.2.
- Updated smoke tests to cover template listing.

## Guardrail

Template diagnostics are workflow evidence only. They do not verify scientific
correctness of formulas, parameters, or results.
