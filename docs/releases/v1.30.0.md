# OpenRepro-Agent v1.30.0

OpenRepro-Agent v1.30.0 adds supervised external-agent adapter specs and validation.

## Added

- `openrepro agent-adapter`
- `openrepro validate-agent-adapter`
- `workspace/agent_adapter.json`
- `workspace/AGENT_ADAPTER.md`
- `workspace/agent_adapter_validation.json`
- `workspace/AGENT_ADAPTER_VALIDATION.md`
- `workspace/agent_trajectory.jsonl`

## Changed

- `refresh` now regenerates and validates the supervised adapter after the safe agent execution dry-run plan.
- The workflow registry includes `agent_adapter` and `agent_adapter_validation` before paper lineage.
- Static dashboards link to adapter and trajectory artifacts when present.

## Guardrails

- Adapter generation does not execute agents or commands.
- Every adapter step requires external supervision and approval.
- Experiments, repairs, human decisions, and claim signoffs remain blocked.
- Adapter outputs do not claim scientific reproduction success.
