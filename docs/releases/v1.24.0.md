# OpenRepro-Agent v1.24.0

OpenRepro-Agent v1.24.0 adds a static multi-agent task board.

## Added

- `openrepro agent-board`
- `reports/agent_board/index.html`
- `reports/agent_board_manifest.json`
- Optional `reports/agent_board.zip`

## Changed

- `refresh` now regenerates the agent board after validating the multi-agent plan.
- `status`, `inspect`, reports, and handoff files now surface agent board status.
- Evidence-package freshness excludes the generated board artifacts because they are downstream coordination outputs.

## Guardrails

- Agent boards are static workflow views.
- They do not dispatch agents.
- They do not execute task commands.
- They do not run experiments.
- They do not close human review decisions.
- They do not add claim signoffs.
