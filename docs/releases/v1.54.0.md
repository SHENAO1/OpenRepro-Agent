# OpenRepro-Agent v1.54.0

v1.54.0 adds supervised execution plans for optional integration adapters.

## Added

- `openrepro integrations run`.
- Dry-run execution planning for MLflow, Aim, DVC, and Hydra targets.
- Generated helper scripts for MLflow, Aim, and Hydra.
- DVC dependency preflight planning.
- `workspace/integration_execution.json` and `workspace/INTEGRATION_EXECUTION.md`.
- Per-target `integrations/*_execution_plan.json` files.

## Policy

Integration execution stays dry-run by default. External tools are invoked only with `--confirm`, and missing optional dependencies are recorded as skipped rather than successful. These reports describe adapter status only; they do not verify scientific outputs.
