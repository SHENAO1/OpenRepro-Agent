# OpenRepro-Agent v1.40.0

v1.40.0 adds durable workflow execution sessions for safe derived workflow steps.

## Added

- `openrepro workflow execute`.
- `workspace/workflow_execution.json` and `workspace/WORKFLOW_EXECUTION.md`.
- Append-only `workspace/workflow_events.jsonl`.
- Per-step stdout/stderr logs under `workspace/workflow_logs/<execution_id>/`.
- Declared output hashes before and after each step.

## Workflow integration

- The executor can target a workflow preset or one explicit step.
- It supports dry-run sessions, `--confirm`, retries, `--max-steps`, `--continue-on-error`, and zip-producing steps.
- It reuses the registered workflow action map so existing step guardrails remain centralized.

## Guardrail

The executor runs only safe derived-artifact steps. Source ingestion, human decisions, repair apply, and experiment execution remain explicit commands.
