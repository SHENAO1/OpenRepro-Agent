# OpenRepro-Agent v1.37.0

v1.37.0 adds declarative pipeline spec export, planning, and validation.

## Added

- `openrepro pipeline export/plan/validate`.
- `openrepro.pipeline.yaml`.
- `workspace/pipeline_plan.json` and `workspace/PIPELINE_PLAN.md`.
- `workspace/pipeline_validation.json` and `workspace/PIPELINE_VALIDATION.md`.

## Changed

- Refresh now writes default pipeline plan and validation artifacts before the asset catalog.
- The workflow DAG includes `pipeline_spec` before `asset_catalog`.
- Asset catalogs include `openrepro.pipeline.yaml` as a config asset when present.

## Guardrails

- Pipeline specs are declarations over registered workflow steps only.
- They do not execute commands or prove scientific reproduction.
