# OpenRepro-Agent v1.26.0

OpenRepro-Agent v1.26.0 adds paper-level lineage graphs.

## Added

- `openrepro paper-lineage`
- `workspace/paper_lineage.json`
- `workspace/PAPER_LINEAGE.md`

## Changed

- `refresh` now regenerates paper lineage after the safe agent execution dry-run plan.
- `status`, `inspect`, reports, and handoff files now surface paper lineage status.
- Evidence-package freshness excludes generated paper-lineage artifacts because they are downstream evidence-organization outputs.

## Guardrails

- Paper lineage organizes existing workflow evidence only.
- It does not infer missing paper content.
- It does not verify scientific correctness.
- It does not run experiments.
- It does not fabricate metrics or results.
- It does not claim scientific reproduction success.
