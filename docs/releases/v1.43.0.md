# OpenRepro-Agent v1.43.0

v1.43.0 adds approved sandbox execution for safe agent tasks.

## Added

- `openrepro agent run`.
- `workspace/agent_sandbox_run.json` and `workspace/AGENT_SANDBOX_RUN.md`.
- Append-only `workspace/agent_sandbox_trajectory.jsonl`.
- Per-step stdout/stderr logs under `workspace/agent_sandbox/<run_id>/`.

## Behavior

- Sandbox runs use `workspace/agent_exec_plan.json` as the source of safe steps.
- Execution is dry-run by default.
- Actual execution requires both `--confirm` and `--approve`.
- Only allowlisted safe derived-artifact commands can run.

## Guardrail

Experiments, repair apply, human review decisions, and claim signoffs remain blocked outside this sandbox.
