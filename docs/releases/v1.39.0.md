# OpenRepro-Agent v1.39.0

v1.39.0 adds a local content-addressed artifact cache for observed project files.

## Added

- `openrepro cache add/list/verify/gc`.
- `.openrepro/cache/sha256/<prefix>/<sha256>` blob storage.
- `workspace/artifact_cache.json` and `workspace/ARTIFACT_CACHE.md`.
- `workspace/artifact_cache_validation.json` and `workspace/ARTIFACT_CACHE_VALIDATION.md`.

## Workflow integration

- The registered workflow DAG includes `artifact_cache` after `asset_catalog`.
- `openrepro refresh` now generates the artifact cache after the asset catalog.
- Cache outputs are excluded from asset catalogs and evidence fingerprints to keep refreshes stable.

## Guardrail

The cache stores observed local bytes for reuse and drift checks. It does not verify provenance or scientific correctness.
