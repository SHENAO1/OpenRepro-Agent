# OpenRepro-Agent v1.49.0

v1.49.0 adds local GitHub PR summary and comment draft generation.

## Added

- `openrepro github pr-summary/summary`.
- `workspace/github_pr_summary.json`.
- `workspace/GITHUB_PR_SUMMARY.md`.
- `reports/pr_comment.md`.

## Behavior

- Summarizes local CI scaffold state, CI validation, local UI, asset build plan, plugin validation, promotion state, dashboard status, and evidence package freshness.
- Includes local git branch and commit metadata when available.
- Produces a Markdown comment body that can be copied into a pull request or CI comment workflow.

## Guardrail

The command is local-only. It does not call GitHub APIs, inspect remote GitHub Actions results, or infer remote CI success.
