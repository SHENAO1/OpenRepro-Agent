# OpenRepro-Agent v1.10.1

OpenRepro-Agent v1.10.1 adds protocol coverage checks.

## Highlights

- Added `openrepro protocol-coverage`.
- Added `workspace/protocol_coverage.json` and
  `workspace/PROTOCOL_COVERAGE.md`.
- Checked coverage across target claims, required data, required experiments,
  required runs, and acceptance criteria.
- Surfaced protocol coverage status in `inspect`, `status`, reports, handoff
  files, and evidence packages.

## Guardrail

Protocol coverage is an engineering completeness signal. It is not a scientific
reproduction score and does not validate formulas, data semantics, code, or
outputs.
