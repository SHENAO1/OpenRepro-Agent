# OpenRepro-Agent v1.3.0

OpenRepro-Agent v1.3.0 adds data provenance registration to the experiment workflow.

## Added

- Added `openrepro register-data` to record local data file paths, roles, sizes, and SHA-256 hashes.
- Added `openrepro validate-data` to detect missing registered data and hash mismatches.
- Added data contracts to experiment specs and data index snapshots to `run-experiment` outputs.
- Added data registry summaries to `inspect`, `status`, lineage, experiment comparisons, and evidence packages.

## Notes

- Data registration does not copy files or verify dataset semantics.
- Data validation is a provenance guardrail only; scientific data quality still requires human review.
