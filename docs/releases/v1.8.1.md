# OpenRepro-Agent v1.8.1

OpenRepro-Agent v1.8.1 adds guided advance dry-run plans.

## Added

- Added `openrepro advance --dry-run`.
- Added `workspace/advance_plan.json` and `workspace/ADVANCE_PLAN.md`.
- Added next-command selection from open gaps or the next incomplete checkpoint.
- Added advance plan summaries to `inspect`, `status`, reports, handoff files, and evidence packages.

## Notes

- Advance plans are previews only.
- `advance --dry-run` does not execute commands, fill placeholders, repair artifacts, or generate scientific evidence.
