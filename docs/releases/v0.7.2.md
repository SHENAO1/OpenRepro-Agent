# OpenRepro-Agent v0.7.2

OpenRepro-Agent v0.7.2 is a stabilization and release-hygiene update for the
v0.7 workflow.

## Added

- Added candidate review and experiment-run counts to status and inspect output.
- Improved `openrepro status` next-step suggestions for list/review/scaffold
  and run-experiment flows.
- Confirmed smoke scripts cover the v0.7 command set.
- Added release tags for recent versions.

## Policy

This release does not change scientific behavior. It improves workflow
visibility and release traceability only.
