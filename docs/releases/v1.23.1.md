# OpenRepro-Agent v1.23.1

OpenRepro-Agent v1.23.1 adds guarded validation for multi-agent coordination plans.

## Added

- `openrepro validate-multi-agent-plan`
- `workspace/multi_agent_plan_validation.json`
- `workspace/MULTI_AGENT_PLAN_VALIDATION.md`

## Changed

- `refresh` now validates the multi-agent plan after regenerating it.
- `status`, `inspect`, reports, and handoff files now surface multi-agent plan validation status.
- Evidence-package freshness excludes the new validation artifacts because they are downstream coordination outputs.

## Guardrails

- Validation is read-only.
- It does not execute agents.
- It does not run experiments.
- It does not close human review decisions.
- It does not add claim signoffs.
- It does not fabricate missing scientific artifacts.
