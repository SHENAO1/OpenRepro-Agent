# OpenRepro-Agent v1.8.0

OpenRepro-Agent v1.8.0 adds normalized workflow checkpoints.

## Added

- Added `openrepro checkpoints`.
- Added `workspace/workflow_checkpoints.json` and `workspace/WORKFLOW_CHECKPOINTS.md`.
- Added checkpoint summaries for source ingestion, analysis, planning, candidate review, data provenance, experiment scaffolds, inputs, specs, run evidence, quality gates, lineage, claim trace, scorecard, and gaps.
- Added checkpoint status to `inspect`, `status`, reports, handoff files, and evidence packages.

## Notes

- Checkpoints are workflow progress markers only.
- A complete checkpoint set does not prove that a paper has been scientifically reproduced.
