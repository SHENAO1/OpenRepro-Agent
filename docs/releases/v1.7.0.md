# OpenRepro-Agent v1.7.0

OpenRepro-Agent v1.7.0 adds workflow readiness scorecards.

## Added

- Added `openrepro scorecard`.
- Added `workspace/reproduction_scorecard.json` and `workspace/REPRODUCTION_SCORECARD.md`.
- Added readiness dimensions for paper evidence, candidate review, data provenance, experiment specs, run evidence, quality gates, repeatability evidence, and claim trace health.
- Added scorecard summaries to `inspect`, `status`, handoff files, and evidence packages.

## Notes

- Readiness scores summarize workflow evidence completeness only.
- A high readiness score is not a scientific reproduction score and does not prove paper results were reproduced.
