# OpenRepro-Agent v1.14.0

OpenRepro-Agent v1.14.0 adds claim signoff validation.

## Added

- Added `openrepro validate-claim-signoffs`.
- Added `workspace/claim_signoff_validation.json` and `workspace/CLAIM_SIGNOFF_VALIDATION.md`.
- Detected stale signoff snapshots, orphan signoffs, incomplete accepted claims, and failed binder validation.
- Surfaced claim signoff validation status in `inspect`, `status`, reports, handoff, and evidence packages.

## Policy

Claim signoff validation checks workflow decision freshness and coverage. It does not prove scientific reproduction.
