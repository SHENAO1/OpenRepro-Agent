# OpenRepro-Agent v0.8.0

OpenRepro-Agent v0.8.0 improves paper evidence provenance for rule-based
candidate extraction.

## Added

- Added `workspace/paper_metadata.json` with title guesses, DOI candidates, and
  source summaries.
- Added source path, chunk index, page number, context window, and evidence
  quality to formula candidates.
- Added numeric values, normalized units, context window, and evidence quality
  to parameter candidates.
- Added richer table/page provenance for PDF table-derived parameter
  candidates.

## Policy

Evidence provenance is a review aid. DOI candidates, title guesses, formula
candidates, parameter candidates, and quality scores are heuristic and require
human confirmation.
