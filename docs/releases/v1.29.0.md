# OpenRepro-Agent v1.29.0

OpenRepro-Agent v1.29.0 adds project reproducibility lockfiles and lock validation.

## Added

- `openrepro lock`
- `openrepro validate-lock`
- `openrepro.lock.json`
- `workspace/REPRO_LOCK.md`
- `workspace/repro_lock_validation.json`
- `workspace/REPRO_LOCK_VALIDATION.md`

## Changed

- `refresh` now regenerates and validates the reproducibility lock before run evidence refresh.
- The workflow registry includes `repro_lock` and `repro_lock_validation` before experiment execution.
- Static dashboards link to lock and validation Markdown artifacts when present.

## Guardrails

- Lockfiles capture engineering reproducibility metadata only.
- They do not verify dataset semantics.
- They do not verify mathematical correctness.
- They do not claim scientific reproduction success.
