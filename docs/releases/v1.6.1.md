# OpenRepro-Agent v1.6.1

OpenRepro-Agent v1.6.1 adds claim trace validation for freshness and link integrity.

## Added

- Added `openrepro validate-claims`.
- Added `openrepro trace-claims --validate`.
- Added `workspace/claim_trace_validation.json` and `workspace/CLAIM_TRACE_VALIDATION.md`.
- Added claim trace validation status to `inspect`, `status`, `diagnose`, and evidence packages.
- Added stale trace and broken-link checks across candidates, experiment specs, registered data, and run evidence.

## Notes

- Claim trace validation checks workflow evidence links only.
- A passing validation result does not prove that any paper claim has been scientifically reproduced.
