# OpenRepro-Agent v1.10.0

OpenRepro-Agent v1.10.0 adds workflow-level reproduction protocols.

## Highlights

- Added `openrepro protocol`.
- Added `workspace/reproduction_protocol.json` and
  `workspace/REPRODUCTION_PROTOCOL.md`.
- Summarized target claims, required data, required experiments, and required
  runs from existing workflow evidence.
- Defined acceptance criteria from claim trace, candidate verification, data
  provenance, experiment specs, run evidence, quality gates, scorecard, gaps,
  and review workflow state.
- Surfaced protocol status in `inspect`, `status`, reports, handoff files, and
  evidence packages.

## Guardrail

Protocols define workflow acceptance criteria only. They do not claim that the
paper has been reproduced or that scientific outputs are valid.
