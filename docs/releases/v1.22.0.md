# OpenRepro-Agent v1.22.0

OpenRepro-Agent v1.22.0 adds role-based review action plans derived from
readiness review blockers.

## Added

- `openrepro review-action-plan`
- `workspace/review_action_plan.json`
- `workspace/REVIEW_ACTION_PLAN.md`
- Review action plan status fields in `inspect`, `status`, reports, handoff,
  refresh runs, and CLI output.

## Policy

Review action plans are advisory workflow task lists only. They do not execute
commands, close decisions, or claim scientific reproduction success.
