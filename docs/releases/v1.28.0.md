# OpenRepro-Agent v1.28.0

OpenRepro-Agent v1.28.0 adds a local run index, static run explorer, and indexed run comparisons.

## Added

- `openrepro runs index`
- `openrepro runs list`
- `openrepro runs show`
- `openrepro runs compare`
- `workspace/run_index.json`
- `workspace/RUN_INDEX.md`
- `workspace/run_index_comparison.json`
- `workspace/RUN_INDEX_COMPARISON.md`
- `reports/run_explorer/index.html`
- `reports/run_explorer_manifest.json`
- Optional `reports/run_explorer.zip`

## Changed

- `refresh` now validates registered data before run-evidence refresh.
- `refresh` now regenerates the run index before lineage.
- The workflow registry includes `run_index` as the quality-gate-to-lineage observation step.
- Static dashboards link to the run index and run explorer when present.

## Guardrails

- Run indexes summarize observed engineering artifacts only.
- Indexed run comparisons report metric and artifact differences only.
- They do not claim scientific reproduction success.
