# OpenRepro-Agent v0.9.0

OpenRepro-Agent v0.9.0 connects human-verified candidate evidence to runnable
experiment template inputs.

## Added

- Added `experiments/<id>/experiment_inputs.json`.
- Added verified-candidate to parameter-value mapping.
- Added input completeness checks for template-required inputs.
- Added `OPENREPRO_EXPERIMENT_INPUTS` for scaffold runners.
- Added `configs/experiment_inputs_snapshot.json` to run-experiment outputs.

## Changed

- BOC-like and numeric-sweep templates now read mapped inputs when available.
- Experiment run reports and handoff files now surface input completeness and
  parameter mappings.
- Updated run-experiment required artifacts for input snapshots.

## Guardrail

Experiment inputs are implementation inputs derived from human-reviewed
candidates. They do not prove that formulas, parameters, code, or outputs are
scientifically correct.
