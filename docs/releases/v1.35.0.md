# OpenRepro-Agent v1.35.0

v1.35.0 adds a unified project asset catalog.

## Added

- `openrepro catalog build/list/show/graph`.
- `workspace/asset_catalog.json`, `workspace/ASSET_CATALOG.md`, and `workspace/ASSET_CATALOG_GRAPH.md`.
- Asset records for source, data, experiment, run, report, handoff, workspace, and config assets.
- Simple asset relations for roots, experiment/run containment, and run-to-experiment links.

## Changed

- Refresh now writes the asset catalog after workflow preset.
- The workflow DAG includes `asset_catalog` as a derived delivery step.

## Guardrails

- Asset catalogs organize observed project files and logical workflow assets only.
- They do not verify scientific correctness or claim reproduction success.
