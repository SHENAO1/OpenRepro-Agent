# OpenRepro-Agent v1.21.0

OpenRepro-Agent v1.21.0 adds a final readiness review report for human handoff.

## Added

- `openrepro readiness-review`
- `reports/readiness_review.json`
- `reports/READINESS_REVIEW.md`
- Optional `reports/readiness_review.zip`
- Readiness review status fields in `inspect`, `status`, reports, handoff,
  refresh runs, and CLI output.

## Policy

Readiness reviews organize final workflow state for human review only. They do
not claim scientific reproduction success, and generated readiness review files
are excluded from evidence-package freshness fingerprints.
