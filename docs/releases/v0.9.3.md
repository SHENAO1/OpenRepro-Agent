# OpenRepro-Agent v0.9.3

OpenRepro-Agent v0.9.3 adds repeat experiment execution and same-experiment
comparison artifacts.

## Added

- Added `openrepro rerun-experiment` for repeat execution of a verified
  experiment scaffold.
- Added `openrepro compare-experiments` for comparing the latest two runs of
  one experiment id, or two explicitly provided run directories.
- Added `workspace/experiment_comparison.json` and
  `workspace/EXPERIMENT_COMPARISON.md`.
- Added normalized input hashing to compare experiment input snapshots while
  ignoring timestamp refreshes.
- Added lineage repeat groups, repeat run indexes, and repeat run counts for
  `run-experiment` outputs.

## Policy

Experiment comparisons report engineering evidence only: metrics, hashes, and
repeat-run provenance. They do not claim paper reproduction success.
