# OpenRepro-Agent v1.51.0

v1.51.0 adds a lower-friction golden path and a simple open-paper toy workflow.

## Added

- `openrepro start <project>` for the first-run paper-to-evidence path.
- Packaged random-search notes based on Bergstra and Bengio 2012, "Random Search for Hyper-Parameter Optimization".
- `random-search-toy` experiment template with deterministic same-budget grid-search/random-search evidence.
- `workspace/golden_path.json` and `workspace/GOLDEN_PATH.md`.

## Policy

The random-search workflow is a compact toy demonstration of one qualitative paper claim. It is workflow and execution evidence only, not a full scientific reproduction of the JMLR paper.
