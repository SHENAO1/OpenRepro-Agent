# v1.59.0

v1.59.0 adds supervised agent result intake and validation so external runner output can be imported back into OpenRepro without bypassing review guardrails.

## Added

- `openrepro agent-result ingest`
- `openrepro agent-result validate`
- `workspace/agent_results.json`
- `workspace/agent_results.jsonl`
- `workspace/agent_result_validation.json`
- `workspace/AGENT_RESULT_REVIEW.md`

## Integrated

- Result validation is now part of the registered workflow DAG after `agent-task-spec`.
- `refresh` regenerates result validation reports without importing new results.
- `status`, `inspect`, cockpit, local UI, and evidence packages surface result counts, validation status, issues, and human-review counts.

## Guardrails

Imported agent results are workflow evidence only. Validation checks schema fields, task ids, Evidence Graph node ids, artifact path safety, forbidden commands, and policy acknowledgement. It does not execute agents, run experiments, close human decisions, add claim signoffs, or prove scientific reproduction.
