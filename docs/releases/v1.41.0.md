# OpenRepro-Agent v1.41.0

v1.41.0 adds local remote transfer support for the artifact cache.

## Added

- `openrepro cache remote-add/remote-list/push/pull/restore`.
- `workspace/artifact_cache_remotes.json` and `workspace/ARTIFACT_CACHE_REMOTES.md`.
- `workspace/artifact_cache_push.json` and `workspace/ARTIFACT_CACHE_PUSH.md`.
- `workspace/artifact_cache_pull.json` and `workspace/ARTIFACT_CACHE_PULL.md`.
- `workspace/cache_restore_plan.json` and `workspace/CACHE_RESTORE_PLAN.md`.

## Remote behavior

- Local remotes copy content-addressed blobs to `<remote>/sha256/<prefix>/<sha256>`.
- Push writes a remote manifest at `<remote>/openrepro_cache_remote.json`.
- Pull copies blobs into `.openrepro/cache/sha256/` and refreshes the local cache index from the remote manifest.
- Restore is a dry-run unless `--confirm` is passed. Changed files also require `--overwrite`.

## Guardrail

Only local remotes are executable in this release. `s3` and `ssh` remotes can be recorded as declarations for future work but are rejected by transfer commands.
