# OpenRepro-Agent v1.4.0

OpenRepro-Agent v1.4.0 adds run quality gates for execution evidence.

## Added

- Added `openrepro quality-gate` for latest-run or explicit-run quality checks.
- Added automatic quality gate reports for `run-experiment`.
- Added checks for manifest validity, runner completion, required metrics, spec snapshots, data snapshots, and environment snapshots.
- Added quality gate status to `inspect`, `status`, lineage, and evidence packages.

## Notes

- Quality gates check evidence completeness only.
- A passed quality gate is not a paper reproduction claim.
