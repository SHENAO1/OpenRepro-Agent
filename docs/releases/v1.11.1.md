# OpenRepro-Agent v1.11.1

OpenRepro-Agent v1.11.1 adds protocol readiness preflight checks.

## Added

- Added `openrepro protocol-preflight`.
- Added `workspace/protocol_preflight.json` and `workspace/PROTOCOL_PREFLIGHT.md`.
- Checked protocol readiness, coverage completeness, action plan state, data provenance, experiment specs, quality gates, and review decisions.
- Surfaced preflight status in `inspect`, `status`, reports, handoff, and evidence packages.

## Policy

Protocol preflight checks workflow readiness only. It does not execute experiments, fabricate missing artifacts, or verify scientific correctness.
