# OpenRepro-Agent v1.38.0

v1.38.0 adds experiment-level tracking over indexed run evidence.

## Added

- `openrepro experiments track/list/show/compare`.
- `workspace/experiment_tracking.json` and `workspace/EXPERIMENT_TRACKING.md`.
- `reports/experiments/index.html` and `reports/experiment_tracking_manifest.json`.
- `workspace/experiment_tracking_comparison.json` and `workspace/EXPERIMENT_TRACKING_COMPARISON.md`.

## Changed

- Refresh now generates experiment tracking after the run index.
- The workflow DAG includes `experiment_tracking` before run lineage.
- Dashboards, evidence explorers, and evidence packages can surface experiment tracking artifacts.

## Guardrails

- Experiment tracking summarizes observed workflow runs and artifacts only.
- It does not claim scientific reproduction success.
