# OpenRepro-Agent v0.6.0

OpenRepro-Agent v0.6.0 adds benchmark provenance fields and project run
lineage artifacts.

## Added

- Added `openrepro lineage` to write `workspace/run_lineage.json` and
  `workspace/RUN_LINEAGE.md`.
- Added run lineage hashes for manifests, config snapshots, source indexes, and
  verified candidate artifacts.
- Added benchmark provenance fields: dataset, environment, dependencies,
  paper_source, and expected_runtime_notes.
- Added provenance completeness to benchmark reports, suite task summaries, and
  benchmark indexes.

## Policy

Lineage and benchmark provenance are audit evidence. They do not claim
scientific reproduction success or benchmark scores.
