# OpenRepro-Agent v1.0.0

OpenRepro-Agent v1.0.0 adds project-level evidence packages for auditable
handover.

## Added

- Added `openrepro evidence-package`.
- Added `reports/evidence_package.json`.
- Added `reports/evidence_package.md`.
- Summarized project status, inspect output, workspace artifacts, experiment
  scaffolds, run manifests, lineage, benchmark indexes, reports, and handoff
  completeness.
- Added v1.0.0 regression tests and smoke coverage for evidence package
  generation.

## Policy

Evidence packages report workflow evidence and known limitations only. They do
not claim scientific reproduction success.
