# OpenRepro-Agent v1.58.0

v1.58.0 adds runner-neutral supervised agent task specs so external agents can receive structured reproduction tasks and return reviewed result events without bypassing OpenRepro guardrails.

## Added

- `openrepro agent-task-spec`.
- `workspace/agent_task_spec.json`, `workspace/AGENT_TASK_SPEC.md`, and `workspace/agent_result_schema.json`.
- Task contracts derived from agent dispatch, agent execution dry-runs, and the Evidence Graph.
- Agent task spec status in project status and evidence packages.
- Agent task spec execution in the registered workflow DAG and refresh pipeline.

## Policy

Agent task specs are contracts for supervised handoff only. They do not execute agents or commands, close human decisions, add claim signoffs, run experiments, fabricate evidence, or claim paper reproduction success.
